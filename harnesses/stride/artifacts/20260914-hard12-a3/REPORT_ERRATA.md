# 公开资料的补充说明与勘误

本文件在最终公开包检查时新增。已经封存的逐题轨迹、事后 judge 和批次报告保持原样；以下说明用于准确解读它们。

1. `evaluation/BATCH_ANALYSIS.md` 第 7 节提到保留“原失败日志”。准确情况是：首次 judge 离线测试的 Windows 临时目录权限失败保存了**错误摘要与处置说明**，见 `cohort/judge-validation-note.json`；`cohort/judge-offline-tests.log` 保存后续成功运行日志。包内没有首次失败的完整 traceback 文件。
2. 发布阶段额外通过 3 项回归测试，涵盖部署信息脱敏、原始 HTTP 字节保持、把普通 `elon-musk-...` 文章地址与真实凭据格式区分开。连同采集/核心 242 项、judge 4 项和统计修正 2 项，共 **251 项不同测试通过**。此前封存的报告记载的是当时已完成的 248 项，历史数字不回写。
3. 公开文件生成曾因旧脚本的大量哈希正则分支过慢而中断，又在扫描中发现将 `musk-...` 词尾误识别为 `sk-...` 凭据格式的情况。最终发布脚本采用一次提取完整 SHA-256 后查表的替换方式，并要求凭据格式前有词边界。原始 HTTP、文档及证据不作内容修改。此过程只涉及离线公开副本，不产生新的 policy 或 judge 调用。
4. `cohort/post_run_source` 保存首次封装时的脚本快照。`publication_source` 保存最终公开副本使用的发布脚本及其测试，仓库 examples 目录也包含当前版本。核心 a3 运行版本和采集器仍按逐题冻结计划核对，未改动。

最终公开文件字节以根目录 `MANIFEST.sha256.json` 为准。首次部分生成的公开副本留在本地，未推送；正式公开包含所有 12 题完整数据。
