# q771：单页人物故事直接支持品牌名称

本题要求识别一位帽店经营者与子女在 1980s 创建的青年品牌。模型在 3 轮后合法提交 `Vakkorama`，refs=[e1]。核心名称、合作对象和年份均由同一原文直接支持；城市古塔和帽子不再流行的背景没有逐项建立。此报告写作时未读取标准答案，语义 judge 单独记录。

## 1. 执行身份与预算

核心 release `5d7752be94a9d40aa757383d8899504bc0f81e81`、包 `0.1.0a3`、协议 `stride-search-3`；EB-GLM-5.2/glm-5.2、temperature=0。只读 CPU SQLite FTS5，OR/BM25 和 compiled_query_cache=False 不变。完整 Config 见 manifest.json：64 模型请求、200 动作、120 后端调用、48,000 输出 token、1,800 秒；上下文 96,000 字节、响应预留 4,096 字节、单次输出 4,096 token。一次自然运行。
