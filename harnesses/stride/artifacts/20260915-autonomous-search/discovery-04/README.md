# 第四轮开发实验完整轨迹

本轮只运行 q774、q771、q778 三题，每题比较 baseline 与 middle-history-v1，共六个独立运行；这是三题部分实验，不是完整四题开发集或十二题复验。

两臂均为 2/3：q774 两臂都耗尽模型调用且最终答案为空；q771、q778 四个控制运行均提交答案，封存后的 judge 均判为正确。不能据此认为历史散文省略提高了任务成功率。

本轮使用 47 次策略模型请求和 4 次 judge 请求，共 51 次。当前新授权的 1000 次额度累计使用 173 次，剩余 827 次；历史总账记录另行保留。

本目录保存六个运行的完整请求、响应、工具调用、原始证据和逐轮阅读视图，以及 judge 原始请求与响应。51 次 HTTP 请求对应的 102 个请求/响应 body 文件与私有原件逐字节一致。公开 SQLite 仅脱敏部署身份并重建事件哈希链，原始内容对象保持不变；原私有封存文件未修改。

`PUBLICATION_CHECKS.json` 记录发布核验结果，`ARCHIVE_HEAD_MAP.json` 记录私有与公开事件链对应关系，`MANIFEST.sha256.json` 提供本目录文件校验值（不包含自身）。本目录不包含凭证、部署配置、预算数据库或标准答案数据库；judge 输入包含本轮已提交答案所需的判分材料。
