# 第七轮开发实验完整轨迹

本轮使用冻结运行代码 `f919885`，比较 baseline 与 relation-review-memory-v1，完成四题八个策略槽及封存后判分。这是四题开发实验，不是十二题独立复验。

两臂均为 2/4，配对 0 胜、0 负，p=1。q775 baseline 提交 Akure, Nigeria，处理臂未合法提交；q774 两臂均弃答；两个控制题两臂均判对。合法提交不等于正确，本轮没有观察到正确率提升。

处理臂 q775 保存一次搜索意向，后续八次全部呈现；q774 保存一次未验证审阅，后续四次呈现、一次因容量省略。记录保持模型意见标签，不构成来源证据或额外引用授权。两题均未因记忆获得完整关系验证。

本轮共有 67 次策略模型请求、5 次 judge 请求，共 72 次。新授权的 1000 次额度累计使用 378 次，剩余 622 次。所有策略槽已封存，无未运行槽。

本目录保留 8 个 SQLite、全部策略及 judge HTTP、工具调用、原文和逐轮阅读视图。144 个 HTTP body 文件与私有原件逐字节一致；SQLite 仅脱敏部署身份并重建事件链，原始私有 seal 不变。

PUBLICATION_CHECKS.json 保存发布检查，ARCHIVE_HEAD_MAP.json 保存事件链对应关系，MANIFEST.sha256.json 覆盖本目录除自身外的全部文件。目录没有凭证、私有部署配置、预算数据库或标准答案数据库；judge 请求保留实际判分输入。发布未调用模型或补跑检索。
