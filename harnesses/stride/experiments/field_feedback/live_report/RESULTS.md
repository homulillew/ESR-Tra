# q778 字段级错误反馈：真实续程结果

本次真实模型对照未观察到恢复收益。A1、B1、B2、A2 各发送四次新请求，十六次均返回 `{"answer": 21, "refs": ["e1"]}`，其中 `answer` 始终为 JSON 整数。四槽都没有自主修正类型，也没有合法提交；均按注册方案结束于 `local_continuation_cap`。

**建议保留字段级反馈作为可选诊断信息，不把它视为已验证的 q778 修复方案，不据此改为默认模式。** 本结果只说明：在这个固定前缀、这个真实服务及每槽四次的观察范围内，仅增加字段与类型说明不足以促成恢复。不能据此断言所有题目或更长续程都无效。本轮停止，不追加调用或叠加机制。

## 实验条件和实际验收

四条独立续程都由真实 R1–R4 重放产生，从 R5 起取得全新响应。A 使用 `validation_feedback="legacy"`，B 使用 `validation_feedback="field"`；运行顺序为 A1 → B1 → B2 → A2。原题、工具 schema、SYSTEM、temperature=0、tool_choice、max_tokens、原 Config、CPU 检索、shelf 和终答策略均保持不变。起点的模型/动作/后端/输出余额为 60/196/113/47648，仍为 RESEARCH。

请求模型为 `EB-GLM-5.2`，十六次实际返回身份均为 `glm-5.2`，HTTP 均为 200，`finish_reason` 均为 `tool_calls`。真实部署来自经原文件哈希核验的私有 manifest；公开占位地址未用于发送。无身份异常、截断、重试、探针或 judge。

三个判断分别为：

- **结构修正失败。** 十六次原始 HTTP 响应都给出整数 answer；没有字符串修正，也没有程序转换。
- **答案信息保持。** 所有尝试仍表达同一个年龄 21；未观察到答案漂移。这里是对已读原文的离线核对，不是新官方评分。
- **引用对象有效且原文支持答案。** `e1` 与原运行已交付窗口逐字段相同，在十六个新请求中均可见；原文明确给出母亲生育时的年龄为 21。由于 answer 类型先被拒绝，实际 finish 没有进入来源检查阶段，不能把离线引用核对记作合法提交。
