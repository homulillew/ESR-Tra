# 保存审阅意见：依据和反例

持续可见的信息可能帮助后续决策，也可能放大错误。本轮只测试一条真实模型审阅的有界保留；保存的内容始终是模型意见，来源和原文授权保持独立。

- [IterResearch: Rethinking Long-Horizon Agents with Interaction Scaling](https://arxiv.org/html/2511.07327v2)，2026-01-31 v2。模型在一次生成中产生思考、报告和动作，以问题、报告及最近交互重建状态，不必额外调用摘要器。但训练后49.1与36.5的比较还涉及训练及不同上下文配置，不能归于单独记忆保留；免训练部分也比较整个重建范式，没有隔离“只保留报告”的收益。原方法持续修订报告，与本轮仅保存一次意见不同。
- [When Does Memory Help Multi-Trajectory Inference for Tool-Use LLM Agents?](https://arxiv.org/html/2605.28224v1)，2026-05-27。知识图谱问答中蒙特卡洛树搜索加入反思记忆后准确率23.2到34.8，但另一 pass@5 比较为31.9到33.3，五题救回、四题退化，p=1.0。Terminal-Bench也有救回和退化并存且不显著的结果。反思每轨迹新增一次模型调用，事实抽取还可能新增调用及嵌入去重；这些成本不能移植成“免费记忆”的收益。本轮没有多轨迹搜索、奖励过滤或嵌入模型。
- [The Memory Trust Gap: Capability-Dependent Failures in Persistent-Memory Agents](https://arxiv.org/html/2609.01852v1)，2026-09-01。合成任务让旧记忆与权威工具信息冲突，部分小模型在标为新近的旧信息下完全依赖旧值，准确率大幅下降。标签、日期、位置会改变信任，但并不可靠地防止错误。该任务及模型与当前实体搜索不同，不能量化当前风险；它明确反驳了“加未验证标签即可保证安全”的假设。

这些论文没有证明一次静态审阅保留能提高同一 GLM、只读 BM25 和16次总请求下的准确率。本轮仅借鉴信息持续可见的机制，并记录静态意见过时、错误锚定和输入成本的风险。原始响应与证据范围哈希用来追溯意见来源，不用于给意见授予事实权威。

本轮与 baseline 的真实比较只能支持联合决策协议的效果。若有效，尚不能分别归因于审阅任务、历史呈现、临时工具限制或后续保留；旧轮次的失败不构成这些组件的随机对照。
