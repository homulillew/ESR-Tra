# 关系审阅的论文依据和适用限制

本研究考察在有限模型请求内，单次审阅能否纠正实体关系混淆。模型需要明确关系主体、比较边界和实际来源支持，再选择检索动作。模型产生的审阅本身不构成事实证据。

- [Inference-Time Scaling of Verification: Self-Evolving Deep Research Agents via Test-Time Rubric-Guided Verification](https://arxiv.org/html/2601.15808v2)，2026-04-29 的 v2。论文的错误答案识别 F1 为完整方法 73.17、去掉外部证据 25、去掉问题分解 61.54；这是错误识别指标，不是任务答案准确率。Claude 的 GAIA 结果从 51.11 到四轮 63.33，但十轮为 62.22，说明增加核查轮次未必继续改善。论文还报告正确变错与错误变对的条件比例，它们分母不同，不能直接相减。完整方法使用额外核查与工具预算，不能视作本轮一次原生动作请求的直接证据。
- [FineVerify](https://arxiv.org/html/2606.00660v1)，2026-05-30。共享四候选池比较中，GPT-5-mini 为 67.4，而置信度选择 64.7、答案聚合 66.3；不能把相对单次生成 59.2 的全部差值归功于核查。Gemini 的相应 76.9 与聚合 76.8 接近，另一测试还有负向结果。把未找到支持当作支持会降低表现。BrowseComp-Plus 的生成器与核查器工具能力也有差异，因此这里仅采用“未证实不能当成已支持”的证据边界，不引用其总增益预测当前模型。
- [Budget-Aware Tool-Use Enables Effective Agent Scaling](https://arxiv.org/html/2511.17006v1)，2025-11-21。完整方法、去规划、去核查、两者都去的比较为 18.7、17、15.4、14.6，说明应在统一预算下考察规划与核查。论文预算以工具使用为单位，还包含计划、核查、摘要、重试与选择，不能等同于本研究最多十六次 HTTP 的约束。

本轮的取舍是保留当前授权原文和检索记录，用原模型的一次决策重新检查一条关系，仍走原生 search/read/find 和原计量。它同时改变该次请求的任务说明、历史呈现及可用工具集合，因此结论只能归于完整的 `relation-review-once-v1` 协议；若有增益，尚不能分别归因于其中某一个组成部分。两臂都使用本次真实新运行，温度零也不保证触发前轨迹相同。

相关历史省略、工具交付和最新检索方法的文献及负向结果分别记录在 LITERATURE_HISTORY.md、LITERATURE_ACTIONS.md 和 LITERATURE_NEXT.md。当前没有检索到能直接证明这个单次机制在相同模型、CPU 索引和预算下有效的论文；准确率与控制题回退必须由冻结后的实验回答。
