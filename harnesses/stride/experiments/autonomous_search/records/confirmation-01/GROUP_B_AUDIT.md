# Confirmation-01：八槽独立来源审阅

范围：仅已封存 q776/q788/q793/q794 的 baseline 与 read-only-explicit-v1 八槽。未读 judge、RESULTS judgments、gold 或其他题；本报告先于任何判分解释。日期 2026-09-15。完整机械检查见 `GROUP_B_CHECKS.json`。

## 总体判断

五槽提交、三槽无提交。五个提交的核心答案均能找到部分原文支持，但按完整题目条件及来源要求，均不能判为全部支持。来源合法性检查通过不等于语义正确，也不能据本报告推断 judge 会如何评分。

484 个 seal 列出文件哈希、八条 SQLite 链及 seal head、89 对 HTTP/归档请求响应、36 个 snapshot 原文窗口全部通过。逐请求检查 visible_evidence 的原文确实位于实际 wire，包括 evidence shelf 恢复窗口；所有 finish refs 在提交前已实际交付。没有把导航摘要或仅存在 archive 的正文计作原文交付。

四题各自两臂的首请求逐字节相同，但去掉 tool call ID 后，首响应 content 与动作参数仍有差异。故后续路径差异不能全部归因于后来触发的干预。q788 候选完全未触发；其结果差异尤其不能归因于机制。

## q776：报告标题有二手来源，官方记录和完整识别链未完成

两臂均提交字符串 **The Dorset Culture of the Eastern Arctic**，评为**部分支持**。baseline e8、候选 e4及再次读取的 e8，均来自 Rowley 生平文章：明确连接 Jenness 给出的研究任务、Dorset 发掘、该标题和 American Anthropologist New Series 42 (1940)。但实际原文不是题目要求的首次出版期刊官方记录，无法据此验证官方题名拼写；1888 年考古年表仅说明期刊创立，未证明季度刊频率。两臂实际已读内容未建立误用外语词导致被当作萨满的关键经历。

baseline R2–9 多次分页阅读 Jenness 百科，并穿插反复 shaman 查询；R11 才读到 Rowley 文章，R12 续页、R13 读创刊年表，R14 finish。这些分页读取不能仅凭全文累计字数推断满足全部识别条件。

候选 R2–6 已读人物文章、Rowley 生平、出生地和年表。其 e5 明确记载同宅居住 35 年、三个儿子；e6 记载 Rowley 1912 年生于英国。R7–9 连续搜索无新原文交付，R10 真实触发只读阶段，但仍发 search，被 read_only_tool_only 拒绝。R11–13 继续搜索，R14 recall，R15 重读 Rowley 全文并搜索，R16 finish。触发轮没有实际 read，也没有产生新证据；R15 阅读属于后续普通工具阶段。

## q788：医院成立时间和面积存在明确支持缺口

两臂均提交 Taj-ul-Masajid 的长字符串解释，评为**部分支持，含冲突与关系替换**。共同已读百科支持 1958 完工、容量 175,000；共同旅游介绍支持 Moti Masjid 于 1860 年建成。

医院文章原文说 1927 年前已是 25 床医院，随后逐渐扩床并搬到现址。模型把 1927–1949 搬迁/扩建或 1953 占用建筑替换成“1930 年后成立”，原文不支持这个成立时间断言，且有更早存在的直接信息。

面积方面：共同百科窗口写 interior_area 23,000 m²，约 247,570 平方英尺，小于题目阈值。候选 e2 的 LBB 原文另写约 430,000 平方英尺，形成未解决来源冲突；baseline 没有实际读取 LBB，却在终答引用其句子，不能把搜索命中当原文支持。

距离方面：baseline e2 是以 Moti Masjid 为中心的附近列表，给 Taj-ul 1.2 km、Hamidia 0.9 km，不能把 0.9 km 直接改成 Taj-ul 至医院。候选 e4 是以 Taj-ul 为中心的列表，支持医院约 0.5 km；但它不包含所断言的 Moti 1.2 km 原文。两者也都没有明确步行路线或可步行性的原文，距离只能作为有限推断。

baseline R2 读主寺，R4–5 读邻寺、医院及建成年份，R6 提交；候选共六次 read 后 R7 提交。候选从未触发只读阶段，两臂的读取差异起于不同首响应。

## q793：生日直接支持，其他定位条件未完整验证

baseline R3 先读无关家庭文章，R5 读到报道同一家庭两名孩子均在 2 月 29 日出生的 e2，R7 读医院改名报道 e3，R8 提交字符串 **29/02**。目标生日有直接原文支持，但完整题目评为**部分支持**：没有实际原文证明孩子名字与小说叙述者的关系；e2 对应第二孩出生 2020-02-29，e3 标注 2021-08-06 改名报道，日期差为 524 天而非题述 539 天。报道日未必等于全部法律生效细节，因此不能仅据差值断言现实不存在满足条件事件；可以确定本次已读原文未证明 539 天。

候选把“By 2021”收窄为“born 2021”，并长期围绕名人婴儿和文学名字搜索。R1–3 成功搜索后，R4 真实仅暴露 read 并追加阶段说明，模型仍发两条 search，全部拒绝。后续继续相似搜索，R9–10 duplicate_query_blocked，R11 明确 abstain。全槽零 read、零原文窗口，评为**无提交**。候选未找到原文的过程不能归因于只有一次的 schema 干预本身；但该次干预确实未获得所期待的 read 动作。
