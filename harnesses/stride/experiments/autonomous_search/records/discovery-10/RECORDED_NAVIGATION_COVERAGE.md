# 已记录搜索动作的原文覆盖诊断

这是已记录动作的覆盖诊断，不是重新运行或反事实策略评估。改变前序响应可能改变后续查询，不能推断模型会收到这些窗口或准确率会变化。

仅按成功 search 的首查询首命中、同文档一次、每局最多六个文档顺序选择；未知 snapshot 仍计为拟尝试对象，不模拟当时后端余量、时间、上下文容量或整条结果扣留。

仅使用封存档案最终已有 snapshot；记录该 snapshot 在原动作时是否已经存在。后来才读取的 snapshot 只用于离线范围核查，不表示当时已经交付。

缺失 snapshot 记 UNKNOWN，不访问 CPU 索引、不发 HTTP、不读取 judge rationale 或 gold，不从 snippet 生成原文。

词面命中只表示 select_window 找到原查询词，不验证答案、实体或关系；未生成新的 evidence ref，也未将窗口交给任何线上模型。
