# 第九轮：一次 read 阶段说明的真实结果

本轮完成四题八个自然槽位。项目 judge 对三个实际提交分别给出：基线 q775 错误，候选 q771/q778 正确。把未提交计为任务未完成后，基线为 0/4，候选为 2/4；配对胜 2、负 0，双侧精确检验 p=0.5。独立来源审阅确认候选两个答案都有实际交付原文支持。

这次差异全部发生在没有触发机制的短控制题。两个真正触发机制的难题均未改善，不能把控制题差异归因于新机制，也不能据此宣布研究目标完成。按照实验前公布的数值晋级规则，本轮满足进入独立十二题复验的条件；下一阶段保持同一实现，重新采集两臂，不用历史基线替代。复验仍必须满足其余八题净正确数增加、控制不退化和核心答案来源支持等要求。

## 实现、冻结与离线验收

真实运行 SHA 为 `a18054b7952df9975a450f93d8837a41ead6f515`。唯一变量为 baseline 与 `read-only-explicit-v1`：连续三轮成功搜索但没有新增原文后，在非 FINAL 且剩余调用不少于三次时，最多一次仅提供原 read schema，并在 SYSTEM 末尾说明本次只能读取已授权文档；下一次恢复。模型服务、temperature=0、只读 CPU 索引、工具字段、来源和终答规则、各题两臂预算一致。没有强制 tool_choice，也没有自动替模型读取。

本轮启动前实际完成 103 项定向回归和 511 项全量回归，均通过；全量运行 191.24 秒。测试命令、日志/XML 哈希见 [OFFLINE_TESTS.json](OFFLINE_TESTS.json)。这些是本轮已完成记录，后续复验复用它们时不能另计一次实测。

## 失败过程和来源审阅

q775 候选 R4 实际看到原 read schema、阶段说明和 52 个已授权可读文档，仍返回两个 search，均按合同拒绝；R5 恢复正常工具。全槽没有 read 或已交付原文，R11 合法弃答。基线 R3 已读取原文，R16 提交 Akure，但所引 e1 只支持该作者的局部生平与普通 Booker 信息，不能完成奖项成立年代、获奖作者和成长城市的关系链；judge 判错。错误答案变为弃答没有计为成功。见 [Q775_AUDIT.md](Q775_AUDIT.md)。

q774 候选 R4 有 57 个可读文档，同样返回两个被拒绝的 search，之后没有读取原文，R15 弃答；基线 R16 弃答且全程没有 read。两臂从首响应已经分歧，包含婚姻次数或首次出演时间条件的错误缩窄。阶段说明没有使模型真正执行读取，不能将问题解释成索引无法提供原文。见 [Q774_AUDIT.md](Q774_AUDIT.md)。

q771 候选 e4 [3000,6000) 明确支持父亲与儿子于 1982 年共同创立 Vakkorama。原 answer 为字符串，identity 表示和 e3/e4 引用完整保留。基线只读首段后转回搜索，最后在 FINAL 调用 read 被拒绝，终态 model_budget，不能把它改写成主动弃答。

q778 候选 e1 [0,3000) 明确支持母亲当时 21 岁；原 finish.answer 为 JSON 整数 21，按 string-integer-v1 的 decimal 规则成为 terminal.answer 字符串 `21`，原值、类型和 refs=e1 可追溯。基线 R2 把 queries 编为字符串，未执行该查询；R4 的 read 被 FINAL 拒绝，全程没有原文或 finish。

两个控制的首请求分别逐字节相同，首响应已不同。四个控制槽没有 read_only 事件，16 次请求均无阶段说明；四请求预算无法满足此机制的触发条件。候选来源支持与机制归因必须分开判断。控制的 128 个封存文件、4 条归档链、16 对 HTTP/归档对象、7 个原文窗口均通过独立检查，详见 [CONTROLS_AUDIT.md](CONTROLS_AUDIT.md) 与对应 CHECKS。

## 完整轨迹与结论

完整公开包位于 [discovery-09](../../../../artifacts/20260915-autonomous-search/discovery-09/README.md)，含 8 个 SQLite、77 次 HTTP 的 154 个原始 body、逐轮原文和终态，共 562 文件、MANIFEST 561 项。HTTP body 与私有原件逐字节一致，原 seal 未改，公开归档链验证通过；仅对部署、凭证及本机身份等必要内容脱敏。完整原件和预算库保留私有目录，定位与哈希见 RECORD_IDENTITY.json。旧十二题正式 6/12 保持原样。

当前结论是开发数值门槛通过、机制有效性未证实。下一次独立十二题对照用于检验该差异能否复现及是否覆盖其他难题；不把温度零视为完全确定，也不以两题控制的偶然差异宣布方案提点。
