## 结论及归因边界

候选两槽提交的 Vakkorama 和整数 21 均有实际交付的原文支持。两个 baseline 均因第四次 FINAL 决策仍调用 read，被 final_only 拒绝后达到 model_budget，留下空答案。这里观察到提交结果差异，但四槽均未激活实验机制，不能归因于临时 read 工具限制或 SYSTEM 阶段说明，也不能据此宣称准确率提升。

每槽最多四次模型请求。机制要求三个已完成连续成功搜索轮，且触发时至少剩三次模型请求；四请求控制不可能同时满足。四槽没有 read_only 事件，16 个真实请求均没有追加阶段说明。两题各自两臂首请求 HTTP body 逐字节相同，配置、模型身份相同，原 schema 前缀因完整 body 相同也一致。首响应已经产生不同的查询及散文，因而后续检索路径分歧早于任何可能的干预。temperature=0 并未在这两组重复请求上得到相同输出；无法由现有记录确定服务端分歧原因。

## 来源与基线失败过程

q771 候选 R2 读取百科和人物文章各 [0,3000)，R3 继续读取两篇 [3000,6000)，R4 原生 finish 参数为字符串 `Vakkorama`，refs 为 e3/e4。e4 是人物文章 d1 的完整实际窗口，明确叙述 Vitali Hakko 在 1982 年与儿子 Cem 一同创立新品牌，随后直接命名 Vakkorama 并说明其面向年轻人。该共同创立关系位于窗口内，不依赖标题、导航摘要或被截掉的下一段。e3 提供品牌年代背景；共同创立的关键支持来自 e4。人物文章注明转载 Skylife 生平文章；本检查确认当前归档来源支持该陈述，不把转载当作已独立验证的公司原始记录。

q771 baseline R2 实际读取同两篇的首 3000 字符，尚未覆盖共同创立段落；R3 转为三条品牌搜索；R4 请求 read d14 被 FINAL 合同拒绝。其两个实际原文窗口说明人物、品牌历史及父子身份，但未完整支持 Vakkorama 的共同创立关系。空答是没有合法 finish 的真实终止结果，不能改写成已经答对、解析丢失或主动弃答。

q778 候选 R3 读取 d28 [0,3000)，e1 的原文明确先说明 Riette 与母亲 Riana 的关系，再叙述 Riette 的出生信息和母亲当时 21 岁。相邻句子的主体连续，没有将另一孩子或另一母亲的年龄替换进来。R4 原生 finish 的 answer 是 JSON 整数 21；归档按 string-integer-v1 decimal 转成字符串 `21`，不是模型原始字符串。文中亲属身份本身是当事人主张，不能由年龄句进一步证明生物学亲缘。页面元数据日期 2025-01-01 与正文发布日期 2021-09-17 不一致，两者均原样存在；该差异不改变年龄句的直接支持。

q778 baseline R1 搜索；R2 的 queries 被模型编码为一个字符串而非数组，收到 arguments_invalid，未执行后端搜索；R3 用正确数组重新搜索；R4 请求 read d26 被 final_only 拒绝。整个槽没有实际原文窗口，也没有 finish，因此最终空答。不能把导航命中视为已读证据，也不能将这次格式错误归因于未激活协议。
