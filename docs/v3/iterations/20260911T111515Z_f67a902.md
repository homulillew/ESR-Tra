| 问题及首个有后果的断点 | 最小改动 | 反例与正对照 |

| 审核鉴权失败或检索服务失败后继续发起策略请求 | 完成每项回执并保存批次后终止相关 episode | 401 审核与 403 检索各只调用一次；未知 usage 仍计请求 |
